Core Dropdown Component Demo

Custom dropdown component with Bootstrap 5.3, supporting Reactive Forms, validation and many other features.

1. Basic Dropdown (Required)
Features:
  • Required validation
  • Dynamic placeholder
  • Value change event
  • Focus/Blur events
2. Dropdown with Hint
Features:
  • Optional field
  • Hint text support
  • Selection change event
3. Multiple Selection
Features:
  • Multiple selection
  • Array value binding
  • Ctrl+Click to select multiple
4. Disabled Options
Features:
  • Disabled options in list
  • Pre-selected value
  • Option "Inactive" is disabled
5. Dynamic Size
Features:
  • Size automatically changes based on selected value
  • xs, s → sm size
  • m → normal size
  • l, xl → lg size
6. Disabled Dropdown
Features:
  • Disabled state
  • Form control disabled
