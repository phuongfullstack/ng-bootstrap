Core AutoComplete Component Demo

Autocomplete component with debounce, keyboard navigation, highlight match and many other features.

1. Basic AutoComplete (Required)
Features:
  • Required validation
  • Debounce 300ms
  • Highlight matched text
  • Show group labels
2. AutoComplete with Hint
Features:
  • Min 2 characters to search
  • Limit to 5 results
  • Hint text guidance
3. Grouped Options
Features:
  • Options grouped by category
  • Search across multiple groups
  • Display group name
4. Email with Validation
Features:
  • Email validation
  • Clear button
  • Suggestions from list
5. Allow Free Text
Features:
  • Allow entering text not in the list
  • Still show suggestions if matched
  • Value is the entered text
